# 尺寸追问方法论（measure interview）

目标：用最少的问题拿到建出"精确可用"模型所需的全部尺寸。
原则：**每轮最多问 3 个问题**，全部带默认值/选项（用户可直接说"就按你说的"）。

## 第一轮：确定骨架（3 问以内）
1. **整体外形三围**：长 × 宽 × 高（mm）？——给一个基于描述的推测值让用户确认/纠正。
2. **用途与工艺**：FDM 打印？光固化？装配用还是外观件？——决定公差、壁厚、圆角策略。
3. **关键特征数量级**：有几个孔/槽/凸台？在哪个面上？

## 第二轮：关键特征精确化（按需）
- 孔：直径、深度、通孔还是盲孔、位置（距哪两条边的距离）
- 圆角/倒角：半径多大？哪几条边？
- 壁厚：壳体类必问（打印默认 2.0~2.4mm）
- 角度：斜面/楔形的角度（度）
- 卡扣/配合：与什么配合？间隙多少？（没说就默认 0.2~0.3mm）

## 视觉输入的处理规则
手绘图/照片：
1. 先声明分解结果："我把它理解为一个 30×20×10 的底座 + 顶部 φ8 通孔，对吗？"
2. 只对**图上量得出比例但量不出绝对值**的量发问；比例可靠时先按假设值建模，
   在渲染图上标注"此尺寸为假设，Xmm，可随时改"。
3. 用户提供实物对照物（如"旁边是 A4 纸"）时先按参照物推算再确认。

## 默认值速查（用户说"你定"时）
| 项 | 默认 |
|---|---|
| 壁厚（FDM） | 2.4 mm |
| 孔补偿（自润滑配合） | 孔径 +0.3 mm |
| 间隙（滑动配合） | 0.3 mm |
| 间隙（压紧配合） | 0.1 mm |
| 外圆角 | 2~3 mm |
| 底边防象脚倒角 | 0.4 mm × 45° |
| $fn（曲面） | 96 |
| 盒盖卡扣过盈 | 0.2 mm |

## 多轮修改的约定
- 用户报修改（"孔改 10mm"、"高度翻倍"）→ 只改对应参数，重渲确认，不重建。
- 每轮结束报当前参数表（名称=值），让用户随时纠正任何一个数字。
- 模型参数尽量收敛到 .scad 文件顶部的一组变量，便于用户日后自行改。
