# 3D 打印导出指南

## 格式选择
| 格式 | 适用 | 说明 |
|---|---|---|
| **STL** | 所有切片器 | 通用三角面片，无单位无颜色；切片器按 mm 处理 |
| **3MF** | 现代 slicer（推荐） | 带单位/颜色/多零件，文件小 |
| OFF / AMF | 老工具链 | 备用 |
| DXF / SVG | 激光切割、CNC | 2D 轮廓（先做出 2D 图形再导出） |
| PNG | 给用户看的效果图 | 800×600，多视角各来一张 |

## 精度
- 曲面：`$fn=64~128`；纯直角零件 `$fn=32` 即可，导出更快。
- 小孔多、结构复杂的模型：先 `render_preview` 确认形状，最后才 `export_model`。

## FDM 打印设计规则（建模时就该遵守）
- 最小壁厚 ≥ 1.2mm（3 条挤出线），推荐 2.4mm。
- 悬垂角 ≤ 45°，否则加支撑或改设计（倒角代替圆角）。
- 孔打出来偏小 0.2~0.4mm：建模时孔径加补偿。
- 底面平放最稳；与热床接触的底边做 0.4mm×45° 倒角防"象脚"。
- 大平面易翘边：加 3~5mm 边缘（brim 由切片器加，模型上做大底缘）。
- 配合件间隙：滑动 0.3mm / 紧配 0.1mm / 卡扣过盈 0.2mm。
- 螺纹：OpenSCAD 无真螺旋扫掠，用 `rotate_extrude` + `twist` 近似或
  `linear_extrude(twist=360)` 梯形截面；精密螺纹建议后期在专业 CAD 补。

## 导出后自检清单
1. `export_model` 返回的 facets 数量是否合理（过少 = 曲面成了多边形）。
2. 建议再导一张 PNG 留档。
3. 文件路径报告给用户时用绝对路径。
4. STL 不含单位——回复中明确告诉用户"模型单位 mm，按原尺寸打印"。

## 命令行等价（备用知识）
```
openscad.com -o out.stl model.scad
openscad.com -o out.png --imgsize=800,600 --autocenter --viewall model.scad
```
